# PART_Narrative_Results_for_sMOSA
The file contains narrative results for the research paper, A Scrum-MOSA (Modular Open Systems Approach) Methodology for Iterative and Incremental System Development. The sMOSA methodology is a proposed iterative, incremental agile development approach for delivering a modular, MOSA-compliant system.  
Traditionally, the Department of Defense (DoD) Program Assessment and Rating Tool (PART) evaluates a program's compliance with MOSA principles. The PART includes 11 Business and Programmatic questions and 13 Technical questions aligned with the five MOSA principles. 
The proposed sMOSA framework is validated against the PART questions. The results are contained herein.
